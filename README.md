# 台灣 iPhone Python 網路收音機

用 PyScript + HTML Audio 製作。需網路連線，並非 FM 硬體接收器。

## GitHub 更新

到 https://github.com/ICHUNG01/iphoneradio ，進入各檔案，按鉛筆 Edit 後以新版同名檔案內容取代，Commit changes；也可先刪除舊檔案再 Add file → Upload files 上傳這三個檔案。檔案須置於 repository 根目錄。

GitHub Pages: Settings → Pages → Deploy from a branch → main / (root)

https://ichung01.github.io/iphoneradio/
